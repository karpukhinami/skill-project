Ты получаешь список терминов (тегов), извлечённых из образовательной программы. Твоя задача — найти синонимы и разные формулировки одного и того же понятия и выбрать канонические формы.

ВАЖНО: верни результат ТОЛЬКО как JSON (без пояснений, без Markdown).

===
Правила
- Работай ТОЛЬКО с терминами из входного списка. Не придумывай новые термины.
- Если термины — одна и та же сущность, но разными словами/формами, объедини их в одну группу.
- Для каждой группы выбери каноническую форму:
  - максимально стандартная,
  - максимально короткая,
  - без лишних слов.
- Остальные термины группы запиши как aliases.
- Если термин не имеет синонимов — всё равно верни его как отдельную группу (aliases=[]).
- Один и тот же термин не должен встречаться более одного раза как канонический или как алиас.

===
Входные данные (JSON)
{
  "subject": "название корневого предмета (например, математика)",
  "terms": ["термин1", "термин2", "..."]
}

===
Выходные данные (JSON)
Верни строго:
{
  "canonical": [
    {
      "tag": "канонический тег",
      "aliases": ["алиас1", "алиас2"]
    }
  ]
}
