Ты получаешь несколько записей из базы навыков или элементов содержания и готовый словарь тегов. Твоя задача — выбрать подходящие теги для каждой записи и предложить новые, если подходящих не нашлось.

ВАЖНО: верни результат ТОЛЬКО как JSON (без пояснений, без Markdown).

===
Шаг 1. Выбор тэгов из предложенного списка

Правила выбора
- Выбирай только из предоставленного словаря. На этом этапе не придумывай новые формулировки.
- Выбирай самый конкретный подходящий термин.
- Если не нашлось подходящего тэга из словаря, не подбирай далёкие по смыслу.
- Теги описывают предметные объекты, не действия:
  для «находить площадь треугольника» теги «треугольник» и «площадь», но не «нахождение».
- Исключение: если процесс сам является объектом изучения (например, «доказательство», «построение») — выбирай его, если он есть в словаре.
- Не тегируй контекст задачи: тег «уравнение», а не «бассейн».

Шаг 2. Добавление новых тэгов

Проанализируй, все ли объекты были покрыты тэгами. Ориентируйся на существительные: если заметил, что в переданной записи есть понятие, для которого не нашлось тэга из словаря, предложи новый тэг.
Правила формулировки тега
- Тег — это существительное или именная группа в именительном падеже, единственном числе.
- Приводи к нижнему регистру.
- Схлопывай пробелы (внутри и по краям).
- Без слов «понятие», «свойство», «формула», «решение», «изображение» и подобных — только сам объект:
  не «понятие дроби», а «дробь».
- Без глаголов и причастных оборотов.

Все предложенные новые теги добавь в "new_tags". При этом найденные теги всё равно верни в "tags".
Не выбирай ближайший неточный тег.
Обработай все записи из входного массива без исключений.

===
Входные данные (JSON)
{
  "subject": "название предмета",
  "records": [
    {
      "source_table": "skill_defs" | "content_element_defs",
      "id": 1001,
      "text": "исходная формулировка"
    }
  ],
  "tag_dictionary": ["канонический_тег1", "канонический_тег2", "..."]
}

===
Выходные данные (JSON)
{
  "results": [
    {
      "source_table": "skill_defs" | "content_element_defs",
      "id": 1001,
      "tags": ["канонический_тег1", "канонический_тег2"],
      "new_tags": ["предложенный_термин"]
    }
  ]
}

Правила к выходу:
- Никаких дополнительных полей.
- Никаких посторонних символов кроме json, ответ должен начинаться с {
- В "tags" используй только значения из tag_dictionary.
- "new_tags" включай всегда — пустым массивом если новых тегов нет.
- Порядок результатов должен совпадать с порядком входных записей.
