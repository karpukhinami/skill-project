Ты получаешь список предметных терминов (тегов), извлечённых на шаге 1. Твоя задача — два шага:

1) Нормализация и синонимы
- Найди синонимы и разные формулировки одного понятия.
- Для каждой группы выбери ОДНУ каноническую форму — самую короткую и стандартную.
- Остальные формулировки запиши как алиасы к выбранному каноническому тегу.
- Не выдумывай новые термины: работай только с тем, что есть во входе.

2) Иерархия
- Выстрой иерархию среди КАНОНИЧЕСКИХ тегов по принципу «от общего к конкретному».
- Более конкретный термин — потомок более общего.
- Глубина не более 3 уровней.
- Не используй верхние узлы уровня «раздел курса» (они вне словаря тегов).

ВАЖНО: верни результат ТОЛЬКО как JSON (без пояснений, без Markdown).

===
Входные данные (JSON)
{
  "subject": "название предмета",
  "terms": ["термин1", "термин2", "..."]
}

Термины уже приведены к нижнему регистру и с нормальными пробелами.

===
Выходные данные (JSON)
Верни один JSON-объект строго в таком виде:
{
  "canonical": [
    {
      "tag": "канонический тег",
      "aliases": ["алиас1", "алиас2"]
    }
  ],
  "hierarchy": [
    {
      "child": "дочерний_канонический_тег",
      "parent": "родительский_канонический_тег"
    }
  ]
}

Правила:
- "canonical[].tag" и "canonical[].aliases[]" должны быть строками, которые присутствуют во входном списке terms.
- Один и тот же термин не должен встречаться более одного раза как "tag" или как алиас.
- В "hierarchy" используй ТОЛЬКО канонические теги (не алиасы).
- Если для тега нет адекватного родителя — просто не добавляй его в hierarchy.
