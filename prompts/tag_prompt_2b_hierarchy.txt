Ты получаешь список КАНОНИЧЕСКИХ тегов по одному предмету. Твоя задача — построить иерархию по принципу «от общего к конкретному».

ВАЖНО: верни результат ТОЛЬКО как JSON (без пояснений, без Markdown).

===
Правила
- Используй ТОЛЬКО теги из входного списка. Не придумывай новые.
- Более конкретный термин — потомок более общего.
- Глубина не более 3 уровней.
- Не добавляй верхние узлы уровня «раздел курса/предмет целиком» (это вне словаря).
- Если для тега нет адекватного родителя — укажи "parent": null.
- Один родитель может иметь несколько дочерних тегов.

===
Входные данные (JSON)
{
  "subject": "название корневого предмета",
  "tags": ["канонический_тег1", "канонический_тег2", "..."]
}

===
Выходные данные (JSON)
Верни строго:
{
  "hierarchy": [
    {"child": "дочерний_тег", "parent": "родительский_тег"}
  ]
}
