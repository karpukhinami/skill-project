# skill-project

Веб-приложение на **Streamlit** для извлечения, нормализации и экспорта данных из документов **ФРП** (федеральных рабочих программ) и **кодификаторов** школьных предметов.

## Что умеет

| Режим | Описание |
|-------|----------|
| **ФРП (Excel-таблица)** | Парсит `.xlsx`/`.xls`-файлы, определяет формат столбцов, извлекает навыки (`учебные действия`) и содержание обучения, разбивает на предложения, выгружает JSON |
| **Кодификатор** | Находит нужные листы по имени, парсит их в отдельные JSON-файлы |
| **PDF** | Читает PDF через `pdfplumber`, определяет тип документа (ФРП или кодификатор), объединяет таблицы, выгружает Excel или JSON |
| **ФРП (текст)** | Обрабатывает DOC/DOCX/TXT через эвристики по ключевым разделам |
| **JSON → Excel** | Преобразует JSON с навыками/содержанием в Excel (отдельный лист на каждый предмет) |
| **Объединение JSON** | Склеивает несколько JSON-файлов в один |
| **Сравнение и слияние JSON** | Объединяет файлы с поиском похожих элементов, требует ручного разбора спорных совпадений |
| **Структурирование через LLM** | Отправляет данные в **Anthropic Claude**, разбивает содержание по предметам и классам, редактируемый промпт, результат — JSON |

## Стек

- Python 3
- [Streamlit](https://streamlit.io/) — UI
- pandas, openpyxl — таблицы и Excel
- pdfplumber — PDF
- python-docx — Word
- requests — обращение к Anthropic API

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

API-ключ Claude вводится в боковой панели приложения.

## Выходные данные

- **JSON** с ключами вида `skill_0001`, `content_0001`
- **Excel** с листами по предметам
